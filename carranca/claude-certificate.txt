# Ledger of files Claude has reviewed for bugs/errors. Source files are kept
# clean (no in-file stamp) -- the narrative of what was found/fixed lives in
# claude-mgd-fixes.md instead. This ledger lets `tools/check_claude_seals.py`
# detect when a certified file has changed since its review, so the seal
# can be treated as stale.
#
# Format (pipe-delimited, one entry per file):
#   relative/path/from/repo/root.py|YYYY-MM-DD|crc32_hex|model_id
#
# crc32_hex is zlib.crc32() of the full file content at the time of the
# review, formatted as 8 lowercase hex digits.
# model_id is the Claude model that did the review (e.g. claude-opus-5-5);
# entries before 2026-10-24 have no model_id (unknown).
